# Donut Club digital menu

- website/ : the finished menu. Open index.html in a browser. Links between pages are relative, so keep the four files together. Images are embedded in the pages; fonts load from Google Fonts.
- artifacts-published/ : the exact HTML published as claude.ai artifacts (links point to the live artifact pages).
- source-images/ : original item photos (donut-N, drink-N, savory-N are numbered in menu order) plus the design references.
